# GadgetZone - Product Feedback : Demo Link : https://anu-priya12389.github.io/product-review/

## 📌 Project Description

GadgetZone is a responsive product feedback webpage created for a smart home product called **Smarty Fan**. The webpage allows users to view product information and submit their feedback through an interactive form.

The project demonstrates the use of **HTML, CSS, Bootstrap, and JavaScript** to create a responsive and user-friendly feedback page.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Product information section for Smarty Fan
* Product image display
* Product category badge
* Popularity progress bar
* Star rating system from 1 to 5 stars
* User recommendation option
* Name and email validation
* Comments section
* Submit feedback form
* Popup success message after submission
* Reset button to clear the form

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **Bootstrap 5.3** – Responsive layout and UI components
* **JavaScript** – Form submission and popup message

## ⚙️ How to Run the Project

1. Download or clone the project.
2. Make sure `fan.jpeg` is in the same folder as `index.html`.
3. Open the `index.html` file in any web browser.
4. Fill in all the required feedback details.
5. Click the **Submit** button.
6. A success popup message will appear.

## 💬 Feedback Form

The feedback form collects:

* User name
* Email address
* Product rating
* Recommendation
* User comments

After submitting all required information, the user will receive the message:

> Your feedback has been sent successfully! 😊

## 📱 Responsive Design

The webpage is designed to work across different screen sizes using:

* Bootstrap grid system
* Responsive viewport meta tag
* CSS media queries
* Flexible image sizing
* Responsive buttons and form layout

## 🎯 Purpose of the Project

The main purpose of this project is to demonstrate the creation of a responsive product feedback webpage using front-end web development technologies.
